# Oligarchs

> 4–6 billionaires, generated per playthrough, each with a distinct personality, ambitions, and a behavioral AI that does not care about the player unless forced to.
>
> **Sector distribution is random** across the pool of **5 core sectors** (Food · Tech · Security · Media · Finance) plus **2 optional** (Pharma · Energy). A sector can have **multiple oligarchs**, or **none at all**. You never know which billionaire owns what until the NetFeed tells you.

Implemented by: [src/entities/data/OligarchData.gd](../../src/entities/data/OligarchData.gd) · Resource class.
Generated by: `WorldDirector._generate_oligarchs_async()` → LLMManager → `_on_oligarchs_generated()`.

---

## Identity

| Field | Notes |
|---|---|
| `oligarch_id` | Unique handle (`oligarch_0`, `oligarch_1`, …) |
| `oligarch_name` | First + last, LLM-seeded per run |
| `title` | CEO, Chairman, Director-General, Founder, Chief Architect |
| `sector_of_influence` | Food · Tech · Security · Media · Finance · Pharma · Energy |
| `alive` | Flipped to false on assassination; everything ambient stops but memory persists |

---

## Intrinsic traits — Nature (immutable)

Set once at generation. Float 0.0–1.0. These are the **filter** the world passes through before a billionaire reacts.

| Trait | High end | Low end |
|---|---|---|
| `ruthlessness` | Will burn cities to protect empire | Cautious, avoids collateral |
| `vanity` | Obsessed with public image | Indifferent to perception |
| `paranoia_base` | Sees threats everywhere | Recklessly confident |
| `intelligence` | Brilliant strategist | Blundering, easy to outmaneuver |
| `greed` | Insatiable expansion | Content with what they have |
| `ideology` | True believer in a cause | Pure profit motive |

---

## Ambitions (1–2 per billionaire)

Randomly assigned from the pool below. Drive autonomous actions in `process_world_state()`. Progress accumulates per ambition in `ambition_progress`.

| Ambition | Gate | What it does each cycle |
|---|---|---|
| **Monopolize supply** | `greed > 0.5`, `wealth > 500k` | Acquire competitor in sector; price +15 |
| **Achieve political immortality** | `ideology > 0.4` | Lobby named [politicians](politicians.md); patronage debt accumulates, Senate votes shift |
| **Build a legacy** | `vanity > 0.5`, `wealth > 300k` | Fund public works; public_image +15, tension −5 |
| **Escape** | `paranoia > 70` | Divert funds to offshore escape vessel |
| **Crush the resistance** | `ruthlessness > 0.6`, `awareness_of_player > 30` | Fund militia; security +20, tension +15 |
| **Control the narrative** | `intelligence > 0.5` | Buy media outlet; controversy suppression |
| **Transcend humanity** | `ideology > 0.6`, `wealth > 500k` | Fund augmentation program; tech_price +50 |
| **Purge The Sinks** | `ruthlessness > 0.8` | Advocate "urban renewal"; tension +30, public_image −20 |
| **Privatize currency** | `intelligence > 0.5`, `wealth > 1M` | Lobby for private management of the clearing system; senate_alignment +8 |
| **Insolvency harvest** | `ruthlessness > 0.6`, `greed > 0.6` | Hostile takeover of distressed rivals; self-enriches, tech_price +15 |

## Dynamic state (evolves each cycle)

| Field | Range | Meaning |
|---|---|---|
| `wealth` | int | Total credits. Drains on actions, grows via sector revenue (implicit) |
| `paranoia` | 0–100 | Evolved from `paranoia_base` + tension + player awareness |
| `public_image` | −100…+100 | Media Oligarch can buff, scandals tank |
| `controversy_level` | 0–100 | Headline density; affects `leak_scandal` effectiveness |
| `recent_scandals` | Array[String] | Rolling log |
| `security_spending` | int | Paid to Enforcers; drains wealth |
| `political_influence` | 0–100 | Senate movement capacity |
| `awareness_of_player` | 0–100 | How visible the player is to this billionaire |
| `threat_assessment` | 0–100 | How dangerous the player seems |

## The behavioral loop (`process_world_state`)

Each cycle, each living billionaire runs:

```
1. Paranoia = paranoia_base * 30
   + max(0, tension - 60) * ruthlessness
   + max(0, awareness_of_player - 30) * 0.5
   → clamp 0..100

2. Self-preservation: if paranoia > 60 → spend 5% of wealth on security

3. Vanity response: if vanity > 0.5 and public_image < -20 → PR campaign

4. Greed response: if greed > 0.6 → raise prices in sector

5. Counter-player: if intelligence > 0.6 and awareness > 50 → deploy investigators

6. Ambition pursuit: run gated action for each assigned ambition
```

Each step emits an action into `actions_taken`, consumed by `WorldDirector._apply_oligarch_action()` which mutates the economy and emits NetFeed events.

## Behavioral profiles (dynamic)

Computed by `get_behavioral_profile()`, recomputed every time anyone asks (cheap):

| Profile | Conditions |
|---|---|
| Cornered Tyrant | `paranoia > 70` and `ruthlessness > 0.7` |
| Panicking Coward | `paranoia > 70` and `ruthlessness < 0.3` |
| Beloved Philanthropist | `vanity > 0.7` and `public_image > 30` |
| Desperate Narcissist | `vanity > 0.7` and `public_image < -30` |
| Untouchable Mogul | `greed > 0.7` and `wealth > 2M` |
| True Believer | `ideology > 0.7` |
| Calculating Hunter | `intelligence > 0.7` and `awareness_of_player > 50` |
| Corporate Shark | default fallback |

Profiles feed the LLM prompt in `get_llm_context_string()` — they're how dialogue and NetFeed events get a voice.

## Quirks

1–3 quirks per Oligarch, LLM-seeded. Concrete examples the LLM must embody in dialogue and NetFeed copy:

- *"Refuses to use the word 'poor'. Uses 'unfortunate' or 'inefficient' instead."*
- *"Keeps an antique typewriter on his desk. Hates screens."*
- *"Speaks in third person when angry."*
- *"Has a prosthetic eye that visibly recalibrates when lying."*

Quirks are pure flavor — but flavor that compounds across a run into a character you either love to hate or forget too quickly to kill.
