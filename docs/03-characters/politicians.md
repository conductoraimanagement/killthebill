# Politicians

> 11 elected representatives, procedurally generated per run, each with a distinct personality, faction leaning, and a voting behavior that is *swayed* — but never owned — by oligarch money, public pressure, and the player.

Implemented by: [src/entities/PoliticianData.gd](../../src/entities/PoliticianData.gd) · Resource class.
Generated by: `WorldDirector._generate_politicians_async()` → LLMManager → `_on_politicians_generated()`.
System: [Senate](../02-world/senate.md) — where their votes turn into world change.

---

## Why 11?

Eleven is odd. No ties, no procedural guesswork when a vote lands 5–5–1. Every bill resolves to PASS or FAIL. The number also reads as a *council* — small enough that every name matters, large enough that bribing one person is not a strategy.

## Identity

| Field | Notes |
|---|---|
| `politician_id` | Unique handle (`politician_0` … `politician_10`) |
| `politician_name` | First + last, LLM-seeded per run |
| `title` | Senator, Representative, Chairman of [X] Committee, Speaker |
| `faction` | `CORPORATE_BLOC` · `POPULIST` · `REFORM` · `INDEPENDENT` |
| `seat_district` | Region they represent, or "At-Large" |
| `cause` | Their signature issue (e.g. `labor`, `law_and_order`, `surveillance`) — the LLM weaves it into every speech |
| `alive` | Flipped on assassination; vacancy triggers a replacement |

Faction split per run (target, adjusted by world pressure at generation):

- `CORPORATE_BLOC`: 3–4 — loyal to oligarchs by default
- `POPULIST`: 2–3 — responsive to tension and approval
- `REFORM`: 2–3 — ideological, clean
- `INDEPENDENT`: 2–3 — swing votes, bribable

A run that starts on the brink of revolution may roll more Populists. A run that starts docile may roll more Corporate Bloc. The Senate is shaped by the world before it votes on it.

## Intrinsic traits — Nature (immutable)

Float 0.0–1.0. These filter every bill before the politician commits a stance.

| Trait | High end | Low end |
|---|---|---|
| `integrity` | Defends stated positions publicly, doesn't flip | Will say anything for the moment |
| `corruption` | Takes money readily; cheap to bribe | Cannot be bought, only persuaded |
| `populism` | Votes with the polls; chases approval | Indifferent to public mood |
| `ambition` | Pushes big risky bills, builds coalitions | Content to coast, rarely sponsors |
| `conviction` | Ideologically anchored on `cause` | Pragmatic, trades freely |
| `charisma` | Their speech swings 1–2 peers per vote | Ignored in the chamber |

**Effective corruption** = `corruption × (1 − integrity)`. A politician with high corruption *and* high integrity is a contradiction the LLM will read as "tortured" — someone who takes the envelope and then publicly agonizes. That is a character, not a bug.

## Dynamic state (evolves each cycle)

| Field | Range | Meaning |
|---|---|---|
| `public_approval` | −100…+100 | Polls, NetFeed inflected |
| `oligarch_patronage` | `Dict{oligarch_id: debt}` | Accumulated favors owed to each oligarch |
| `player_leverage` | 0–100 | Blackmail or favor the player has banked |
| `scandal_level` | 0–100 | Exposed corruption; rises on leaks |
| `re_election_proximity` | int (cycles) | Counts down; behavior spikes near zero |
| `recent_votes` | `Array[Dictionary]` | Rolling `{bill_id, stance}` |
| `position_consistency` | 0.0–1.0 | Derived — how often their votes match their stated ideology. Drops on bribe-flips. |

## The voting loop (`evaluate_bill`)

For every bill the Senate hands a politician:

```
1. Ideological fit  = bill.ideological_score · conviction
                    + faction_preference[faction]

2. Patronage pull   = Σ (oligarch_patronage[o] · oligarch_stance[o])
                      · (corruption · (1 − integrity))

3. Populist pull    = populism · public_stance(bill, world)

4. Leverage pull    = (player_leverage / 100) · player_requested_stance

5. Charisma contagion = average(peer_stances_so_far) · 0.2

6. Score = ideological_fit + patronage_pull + populist_pull
         + leverage_pull + charisma_contagion
         ± re-election jitter near the deadline

7. If abs(score) < 0.2 → ABSTAIN
   elif score > 0     → YES
   else               → NO
```

**Roll order matters.** Politicians with highest `charisma` vote first, and their stance feeds step 5 for every later voter. This is how a swing gathers momentum — a Reform firebrand voting NO first can pull two Independents along.

## Behavioral profiles (dynamic)

Computed by `get_behavioral_profile()`. Feeds the LLM prompt so speeches, interviews, and NetFeed coverage all carry a voice.

| Profile | Conditions |
|---|---|
| **The Lifer** | `ambition < 0.3`, `re_election_proximity > 10` — votes with the herd, never sponsors |
| **The Fire-brand** | `conviction > 0.7`, `charisma > 0.6` — sponsors divisive bills, peer-flipper |
| **The Bagman** | `corruption > 0.6`, `integrity < 0.3` — NetFeed calls them "always available" |
| **The Conscience** | `integrity > 0.8`, `corruption < 0.2` — press darling, clean voting record |
| **The Climber** | `ambition > 0.8`, `populism > 0.6` — chases camera time, flip-prone near elections |
| **The Sphinx** | `populism < 0.3`, `conviction > 0.5` — bribes don't work, arguments sometimes do |
| **The Collapsed** | `scandal_level > 70` — already dying; will trade their last vote for a lifeline |
| **The Loyalist** | default; votes with faction unless pressured |

## Player interactions

Each is a concrete action in [src/core/PlayerManager.gd](../../src/core/PlayerManager.gd). All have cost and risk.

| Action | Cost | Effect | Risk |
|---|---|---|---|
| **Bribe** | Credits ∝ `(1 + scandal_level) · (1 − corruption)` | Flip their vote on ONE pending bill | Counter-bribe by a richer oligarch cancels it |
| **Blackmail** | Scandal dossier (built via investigation) | Flip vote permanently on a bill *category* (security / economy / media) | Expires if the scandal leaks independently |
| **Expose** | Scandal dossier | `public_approval −40`, `scandal_level +50` | Faction may disown them, faction balance shifts unpredictably |
| **Recruit as Ally** | `public_approval > 30` + 3 shared votes | They sponsor bills the player suggests | Can still be bribed off by oligarchs |
| **Assassinate** | Weapon + opportunity | Removes them; `_fill_vacant_seat()` rolls a replacement | Heat tier 4, `public_tension +25`, NetFeed martyrdom can flip their faction |

**Replacement politicians** inherit the faction slot but roll fresh Nature traits. A faction can drift over time if its members keep getting killed or exposed — the player rewrites the Senate by attrition, not by election.

## Quirks

1–2 quirks per politician, LLM-seeded. Concrete details that must show up in speeches, interviews, NetFeed coverage:

- *"Refers to constituents as 'the taxpayers' — never 'the people'."*
- *"Ends every floor speech with the same line: 'And that is the will of the people.'"*
- *"Wears the same red tie to every vote. A staffer says it's for luck."*
- *"Calls every opposing senator 'my distinguished friend' while voting against them."*
- *"Has a tell — touches their left cuff before lying."*

Quirks are flavor the player *learns to read*. Knowing the tell turns an interview into a lie detector.
