LLMManager Singleton

The LLMManager is the game's network interface to external AI. It extends HTTPRequest and handles all communication with LLM providers for NPC dialogue generation and NetFeed event streaming. It implements an automatic provider fallback hierarchy to ensure the game always has AI capability.

Provider Fallback Hierarchy

On _ready(), the manager scans OS.get_environment() for API keys and selects the first available provider. If no cloud keys are found, it falls back to a local server.

Provider-Specific Payload Adaptation

STANDARD OpenAI-Compatible

Gemini, OpenAI, Qwen, OpenRouter, and Local all use the standard OpenAI chat completions JSON format with messages array, model, and optional response_format: { "type": "json_object" }.

SPECIAL Claude / Anthropic

Claude uses a different JSON structure: system is a top-level string (not inside messages), requires max_tokens explicitly, uses x-api-key header instead of Authorization: Bearer, and requires anthropic-version header.

SPECIAL OpenRouter

Uses standard OpenAI format but requires additional headers: HTTP-Referer and X-Title for request attribution.

Request Types

request_npc_action(npc, player_input)

Purpose: Generate contextual NPC dialogue or action responses during player interaction.

Flow:

  1. Sets current_request_type = "npc_action"
  2. Builds system prompt from NPCData.get_llm_context_string() + WorldDirector global state
  3. Sends HTTP POST to the active provider
  4. On response, emits llm_response_received(parsed_data)

request_netfeed_events(world_state, oligarchs)

Purpose: Evaluate the complex conjecture of the world state and generate an organic stream of events.

System Prompt Template:

  • "You are the Game Master for a systemic immersive sim called KILL THE BILL."
  • Injects full global_economy dictionary as JSON
  • Injects full oligarchs dictionary as JSON
  • Instructs: generate organic event count based on gravity (uncapped)
  • Events can be public news or invisible systemic shifts
  • Response format: {"events": [{"type": "NEWS_TICKER"|"SILENT_RIPPLE", "headline": "...", "systemic_impact": "..."}]}

On response: Emits netfeed_stream_received(events_array)

Response Parsing

The _on_request_completed() callback handles all responses. It extracts the message.content string from the JSON response, then parses it as nested JSON. Based on current_request_type:

  • "npc_action": Emits llm_response_received(parsed_data)
  • "netfeed_stream": Validates the events key exists, then emits netfeed_stream_received(events_array)

Signals

Signal Payload Emitted When
llm_response_received Dictionary NPC action response parsed successfully
netfeed_stream_received Array NetFeed event stream parsed successfully
llm_error_occurred String HTTP failure, parse error, or missing provider
