Relationships & Agent System

The player's most powerful tool is not a weapon — it's people. By investing time and actions into building relationships with persistent NPCs, the player can recruit them as agents who execute objectives on their behalf. Relationships range from casual acquaintance to romantic partner or loyal operative.

Bond Escalation

Relationships progress through 6 tiers. Higher tiers unlock agent recruitment and increase willingness to accept dangerous objectives.

Tier Name Int Value Can Recruit? Willingness Bonus
0 None 0 No —
1 Acquaintance 1 No —
2 Friend 2 Yes (if trust ≥ 30) +0.0
3 Close Friend 3 Yes (if trust ≥ 30) +0.0
4 Romantic 4 Yes +0.2
5 Loyal Operative 5 Yes +0.3

Trust Mechanics

BUILD Trust Increases

  • Sharing resources (rations, intel)
  • Saving them from Enforcers
  • Successful agent missions: +15 trust
  • Dialogue choices that align with their personality

DECAY Trust Decreases

  • Pushing objectives they refuse: -5 trust
  • Failed agent missions: -20 trust
  • Betraying their location or allies
  • Actions that hurt their immediate_need

Agent Recruitment

Requirements (can_recruit())

  • relationship_type >= 2 (Friend or higher)
  • trust >= 30.0

Objective Assignment (assign_objective())

Willingness Formula

base_willingness = trust / 100.0
  + relationship_bonus (Romantic: +0.2, Operative: +0.3)
  + empathy * 0.1        // Empathetic NPCs want to help
  - greed * 0.1          // Greedy NPCs want payment
  + idealism * 0.1       // Idealists believe in the cause
  - risk_level * (1.0 - aggression * 0.5) * 0.3  // Brave NPCs fear less

willingness = clamp(base_willingness, 0.0, 1.0)
// Success: randf() < willingness

On Refusal

The refusal tone is determined by the NPC's personality:

  • High aggression: "Don't push me. I said no."
  • High empathy: "I want to help, but this is too much."
  • High greed: "What's in it for me?"
  • Default: "I can't do that."

Each refusal costs -5 trust. Pushing too hard erodes the relationship.

Objective Resolution (resolve_objective())

SUCCESS

  • Trust: +15
  • Memory added: "Successfully completed a mission for the player."
  • Bond history logged

FAILURE

  • Trust: -20
  • Stress: +15
  • Memory added: "Failed a dangerous mission. The player put me at risk."
  • If trust drops below 10: relationship degrades one tier

LLM Integration

The relationship state is injected into the LLM context string via get_llm_context_string():

  • "The player is your romantic partner. Trust: 72/100."
  • "You are currently on a mission for the player: 'Distract guards at Depot 7'."

This ensures the LLM voices bonded NPCs with appropriate intimacy, loyalty, or resentment depending on the relationship state.
