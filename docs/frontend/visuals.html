Frontend Systems: Visuals & Interface

The visual language is designed to heavily emphasize class division, utilizing a strictly top-down isometric viewpoint to make the player feel like a piece on a board.

The Isometric Camera

The game uses a fixed 3D isometric perspective. The CameraController script handles panning and zooming, while maintaining the strict X: -30 degrees, Y: 45 degrees orthogonal angle. It follows the player but allows "scouting" ahead.

Art Style: Corporate Brutalism vs. High-Tech Slum

Low Class The Sinks

Geometry: Modular, low-poly blocks. Haphazard construction with verticality blocked by corporate netting.

Lighting: Dark, claustrophobic. Relies heavily on local point lights (flickering neon, barrel fires). Volumetric fog simulates dense smog.

Palette: Grays, rusted browns, toxic greens, and harsh neon pinks.

High Class The Enclave

Geometry: Symmetrical, clean, brutalist architecture mixed with impossible floating structures.

Lighting: Bright, directional lighting (simulating clear sunlight above the smog layer). Soft shadows.

Palette: Stark whites, gold trims, and lush, synthetic greens.

UI Systems

Interface Minimalist HUD

To increase immersion, the UI is diegetic where possible (e.g., ammo counters on the weapon model, health indicated by posture or screen effects).

Interface Terminal UI

Hacking or reading lore occurs via fullscreen "terminal" overlays that look like retro-futuristic DOS interfaces, replacing the 3D view temporarily.
