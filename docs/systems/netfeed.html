NetFeed & Event Stream System

The NetFeed is the game's living narrative engine. It represents the global information network — a constant stream of news, rumors, and invisible systemic shifts that shape the world in real time. Events are generated by the LLM evaluating the complex conjecture of all intersecting world variables.

Design Philosophy

Not every systemic shift makes the news. Some events are public headlines that scroll across the player's NetFeed terminal. Others are silent ripples — invisible shifts in NPC behavior, market prices, or political alignment that the player only notices through changed world behavior. This creates a living world where the player must read between the lines.

Complex Conjecture Model

When trigger_news_cycle() fires, the WorldDirector packages the full state of the simulation and sends it to the LLM:

  • Global Economy: food_price, tech_price, public_tension, security_presence, senate_alignment
  • Oligarch State: Each Oligarch's wealth, paranoia, public_image, controversy_level, and recent_scandals array

The LLM evaluates the intersection of these variables and determines what would logically happen in this specific world state. The number of events generated is uncapped — it varies based on the gravity of the situation.

Event Types

NEWS_TICKER Public Headlines

Visible events that appear on the player's NetFeed terminal. They are appended to the netfeed_history array and broadcast via the netfeed_event_generated signal.

Examples:

  • "Food Oligarch announces 30% price hike on synthetic rations"
  • "Riots erupt in Sector 7 after Enforcer shooting"
  • "Tech mogul donates to Sinks charity — critics call it PR stunt"

SILENT_RIPPLE Invisible Shifts

Events that are NOT shown to the player. They silently alter NPC behavior, market prices, or political alignment. The player only notices the effects — not the cause.

Examples:

  • "Enforcers quietly double patrols in industrial sector" (security_presence +10)
  • "Underground food smuggling ring expands" (food_price -5 in The Sinks)
  • "Senate back-channel deal shifts alignment toward corporate interests"

Data Flow

  1. WorldDirector.trigger_news_cycle() is called
  2. WorldDirector calls LLMManager.request_netfeed_events(global_economy, oligarchs)
  3. LLMManager sends the conjecture to the active LLM provider
  4. LLM returns JSON: {"events": [...]}
  5. LLMManager parses response, emits netfeed_stream_received(events)
  6. WorldDirector's _on_netfeed_stream_received(events) processes each event:
    • NEWS_TICKER: Appended to netfeed_history, emits netfeed_event_generated for UI
    • SILENT_RIPPLE: Logged internally, systemic impact applied silently

Event JSON Schema

{
  "events": [
    {
      "type": "NEWS_TICKER",
      "headline": "Food riots spread to three new sectors",
      "systemic_impact": "public_tension +15, food_price +20",
      "timestamp": 1713400000  // Added by WorldDirector
    },
    {
      "type": "SILENT_RIPPLE",
      "headline": "",
      "systemic_impact": "Security Oligarch quietly funds militia",
      "timestamp": 1713400000
    }
  ]
}
