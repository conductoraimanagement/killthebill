# Victory Conditions — Technical Reference

## Overview
No linear ending. The `WorldDirector` monitors three Collapse Meters simultaneously. First to hit critical mass triggers endgame.

## Path 1: Direct Action (Assassination)
- **Objective:** Kill 3-5 procedurally generated Billionaires
- **Triggers:** Each Oligarch death removes an economic pillar. All Oligarchs dead = total collapse.
- **Challenges:** Each kill spikes Heat to Tier 3 and increases surviving Oligarchs' paranoia.
- **Endgame:** Power vacuum. Violent collapse. Heaviest combat ending.

## Path 2: Systemic Collapse (Economic Hacking)
- **Objective:** Drive all Oligarch `wealth` to zero via Butterfly Effect manipulation.
- **Methods:** Sabotage supply chains, hack finances, leak scandals, shift Senate alignment.
- **Endgame:** The Enclave can't pay Enforcers. Security grid shuts down. Quiet corporate death.

## Path 3: Political Revolution (NPC Persuasion)
- **Objective:** Push `public_tension` to 100. Requires critical mass of radicalized/revolutionary NPCs.
- **Methods:** Build relationships with Idealists, use Persuasion UI to organize, spread propaganda.
- **Endgame:** The masses storm The Enclave. Player must escort mob to the citadel.

## Hybrid Approaches
Paths are not exclusive. Killing the Media Mogul (Path 1) removes propaganda shielding, making scandals (Path 2) more effective and NPCs easier to radicalize (Path 3).

## Roguelite Persistence
On death: new citizen, new Class Seed, same WorldDirector state. Consequences carry over.
