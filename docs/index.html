KILL THE BILL: Documentation Database

Welcome to the Lead Architect's systemic database. This portal contains all technical schemas, variables, and interaction logic for the Godot 4 simulation engine. The game is a 3D isometric immersive sim where the player manipulates a dynamic economy, exploits a PR & Reputation Engine, and recruits persistent NPCs as agents to topple a corporate oligarchy.

Project Snapshot

ACTIVE Phase 3: Core Systems

LLM Network Manager with 6-provider fallback (Gemini → Local). NetFeed event streaming. NPC Nature/Nurture evolution. Relationship & Agent system.

40 Persistent NPCs

Randomized roster per playthrough. 6 intrinsic traits, 56+ quirks, behavioral profiling. Each NPC evolves uniquely through the same world events.

3 Victory Paths

Direct Action (Assassination), Systemic Collapse (Economic Hacking), Political Revolution (NPC Persuasion). All tracked simultaneously.
