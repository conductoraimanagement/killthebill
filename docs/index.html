System Status Overview

ACTIVE Core Singletons

The global brain and state managers are fully mapped. These include the WorldDirector (which handles the butterfly effect and economy) and the PlayerManager (handling traits and archetypes).

The unscripted NPC system relies on an Epidemic Influence model. NPCs use their dynamic state machine payload to interface directly with an LLM for dialogue.

DANGER Direct Action Systems

Loud actions trigger the Heat System, deploying SWAT and Mechs based on the local crime tier. Combat is highly systemic and tied to stealth.
