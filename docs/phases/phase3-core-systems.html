PHASE 3 Core Systems & LLM Integration

This phase wires up the "brain" of the simulation. It connects the procedural NPC data schemas to external LLM APIs to generate dynamic responses, and implements the Social Fabric polling loop.

DONE 3.1: NPCData Resource Expansion

Objective: Strongly type the micro-state of every NPC to ensure the LLM has exact psychological and economic context.

Technical Breakdown:

  • Class: Custom Godot Resource (NPCData.gd).
  • Core Variables: health, wealth, paranoia.
  • Social Variables: social_cohesion (How likely they are to conform to the crowd), defiance_level (How likely they are to rebel against Enforcers).
  • Memory Array: memories: Array[String]. A rolling ledger of the last 5 interactions with the player or major world events to ensure narrative consistency across LLM calls.
  • Serialization: get_llm_context_string() formats the Resource into a highly compressed, token-efficient prompt string to append to the System Prompt.

DONE 3.2: LLM Network & NetFeed Engine

Objective: Create a robust, multi-provider API wrapper that acts as the "Game Master" and generates systemic consequences.

Technical Breakdown:

  • Class: HTTPRequest Singleton Autoload (LLMManager.gd).
  • Ultimate Provider Fallback: On _ready(), it scans `OS.get_environment()` and cascades securely: Gemini -> OpenAI -> Claude -> Qwen -> OpenRouter. If all cloud keys fail, it defaults to a Local Server Loopback (e.g., Ollama llama3 on 127.0.0.1:11434).
  • Dynamic Payload Formatting: Automatically shifts JSON structures depending on the provider (e.g., mapping Claude's max_tokens vs OpenAI's response_format: json_object).
  • Complex Conjecture Generation: The trigger_news_cycle() passes the entire global state (Oligarch wealth, tension, prices) to the LLM. The LLM generates an unconstrained stream of events based on this exact state intersection.
  • Event Types: Parses two specific outputs from the LLM stream:
    • `NEWS_TICKER`: Public headlines appended to the NetFeed.
    • `SILENT_RIPPLE`: Invisible systemic shifts that silently alter the math behind the scenes.

TODO 3.3: Contextual Persuasion UI & NetFeed

Objective: Build the diegetic physical interface (the player's "Datapad") to view the NetFeed and manipulate NPCs.

Technical Breakdown:

  • Node Hierarchy: CanvasLayer -> PanelContainer (CRT-styled terminal).
  • The NetFeed Ticker: A scrolling RichTextLabel that subscribes to the WorldDirector.netfeed_event_generated signal, updating in real-time as the LLM streams events.
  • Hybrid Dialogue System:
    • Dynamic Buttons: A VBoxContainer that auto-populates with standard systemic responses (e.g., [Bribe], [Threaten]) based on the NPC's class.
    • Open Input: A LineEdit text box for the player to attempt "social engineering". This text is sent directly to the LLM.
  • Styling: Must adhere strictly to the corporate-brutalist CSS tokens (neon accents, monospace fonts, dark backgrounds).

TODO 3.4: Social Fabric Polling Loop

Objective: Implement the localized crowd psychology math to simulate riots or pacification.

Technical Breakdown:

  • Execution: A 60-second Timer loop residing inside WorldDirector.gd.
  • Sector Zeitgeist Math:
    Zeitgeist = SUM(NPC.tension) / Active_NPC_Count
  • Conformity Gravity: Iterates through all active NPCs. If an NPC has high social_cohesion, their personal tension is mathematically pulled toward the Sector Zeitgeist. If they have high defiance_level, they resist the pull.
  • Systemic Triggers: If the local Zeitgeist hits a critical mass (e.g., >80), the Sector automatically enters a Riot State, spawning Enforcer drones and locking down travel without direct player involvement.
